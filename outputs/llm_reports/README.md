# LLM-Generated Market State Briefings

This directory contains market state assessments generated by the LLM interpreter (Notebook 09). Each file is a structured regime assessment rendered as a readable markdown briefing.

## Contents

| File | Regime | Description |
|---|---|---|
| `calm_period_2026-02-03T10-00.md` | Calm | Normal entropy, balanced flow, stable metastable levels |
| `crash_info_2026-01-31T14-30.md` | Crisis (information) | Jan 31 crash — entropy collapse, Binance leadership |
| `crash_mech_2026-02-05T22-00.md` | Crisis (mechanical) | Feb 5-6 crash — normal entropy, liquidation cascade |
| `transitional_2026-02-02T08-15.md` | Transitional | Mixed signals with conflicting features |
| `all_briefings.json` | All | Consolidated JSON of all briefings |

## How these are generated

These files are produced by `notebooks/09_llm_market_interpreter.ipynb` Section 8. The pipeline:

1. Physics features are assembled into a `MarketSnapshot` (from `src/llm_interpreter.py`)
2. The snapshot is sent to the LLM with the system prompt (`prompts/market_interpreter_v1.md`)
3. The LLM returns a structured `RegimeAssessment` (JSON)
4. The assessment is rendered as markdown via `RegimeAssessment.to_markdown()`

To regenerate, run Notebook 09 with an active LLM backend (Anthropic API or local Ollama).
